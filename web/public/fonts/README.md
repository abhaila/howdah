# Bundled fonts

DM Sans (variable, weights 100–1000, upright and italic) and DM Mono (400, 500), Latin subset,
as served by Google Fonts. Both are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org): Copyright the DM Sans and DM Mono Project Authors
(https://github.com/googlefonts/dm-fonts, https://github.com/googlefonts/dm-mono).

They are bundled, not fetched, so the viewer reads the same offline (DESIGN.md, Type).
The `@font-face` rules are in `web/public/tokens.css`.
